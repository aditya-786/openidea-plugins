How auto-refresh works

Auto-refresh reads the Actuator while this tab is visible.

One refresh a minute, for at most 10 minutes and the number of refreshes set in Auto-refresh attempts per start. Two failures in a row stop it. Turn on Allow auto-refresh in settings before Start.

Hiding or leaving this tab stops auto-refresh. Stop cancels the next refreshes; use Cancel on the IDE task to cancel a refresh in progress. A failed refresh keeps the previous snapshot.

Only localhost and 127.0.0.1 URLs are read. After a redirect, the answering server isn't checked.
